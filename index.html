FAQ

Questions we get asked a lot

Is my personal data safe?

Yes. Your profile and API keys are stored exclusively in your browser using Chrome's local storage API. Nothing is ever transmitted to our servers — we don't have any. Your data cannot be accessed by anyone else.

Do I need an API key to use it?

No. Without an API key, AI Form Filler uses smart local matching (Levenshtein distance) to fill fields — no AI required. It works for most standard forms right away. An API key unlocks AI-powered matching for ambiguous or complex fields.

Which AI providers are supported?

Claude (Anthropic), OpenAI (GPT-4o), Google Gemini, DeepSeek, Grok (xAI), and OpenRouter — which gives you access to 10+ completely free models including Llama 3, Mistral, and DeepSeek R1.

Does it work on all websites?

AI Form Filler works on any website that uses standard HTML form elements. It also supports shadow DOM (used by Workday and some modern job boards), single-page apps built with React or Vue, and dynamically loaded forms.

Does it work on LinkedIn Easy Apply?

Yes. AI Form Filler detects fields on LinkedIn job applications and can fill them automatically. You can also import your LinkedIn profile directly to populate your AIFF profile.

Does it fill password fields?

No — and that's intentional. Password fields are skipped entirely during detection. Auto-filling passwords is a security risk: a malicious page could trick the extension into exposing a saved credential. Your browser's built-in password manager handles passwords safely. AI Form Filler focuses on everything else — name, email, address, work history, custom fields — and leaves password fields untouched.

I've supported the project — how do I stop seeing the support popup?

After your payment on Polar.sh, you'll receive a license key by email. Open the extension → click the Settings icon → go to the Support tab → paste your key into the "Enter your license key" field and click Verify. Once verified, the popup is permanently disabled on that device.

Will it ever be paid?

The core extension will always be free. We rely on voluntary support from users who find it valuable — starting at $5/year. This keeps development going without gating features behind a paywall.
